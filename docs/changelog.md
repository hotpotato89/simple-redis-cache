# Changelog

Логи версий ведутся начиная с `1.1.0`, как со стабильного релиза.

## [1.4.0] - 2026-08-09

### Added
- Компрессия данных через **lz4** (параметр `compress` в декораторе)
- Параметр `compress_threshold` для настройки порога сжатия (по умолчанию `1024` байта)
- Опциональная зависимость `lz4`: `pip install simple-redis-cache[lz4]`
- Тесты для компрессии (100% покрытие)

### Changed
- Обновлены докстринги для `async` и `sync` версий (добавлены параметры `compress` и `compress_threshold`)

## [1.3.0] - 2026-08-09

### Added
- Поддержка `date`, `time`, `timedelta` в `CustomJSONEncoder`
- Тесты для сериализатора и энкодера (100% покрытие)

### Fixed
- Логика `cache_none` — теперь корректно работает во всех сценариях

### Changed
- Сериализатор вынесен в отдельный модуль (внутренний рефакторинг)

## [1.2.0] - 2026-08-08

### Added
- Добавлена возможность выбора кэшировать `None` или нет
- Добавлены тесты для таких случаев

## [1.1.0] - 2026-07-13

### Added
- Добавлена поддержка `pickle`-сериализации через параметр `use_pickle=True` в декораторе `@cache`
- Добавлен маркер `PICKLE:` для автоматического определения формата при чтении из Redis
- Добавлена обработка `bytes` и `str` при чтении из Redis
- Добавлены тесты для `pickle`-режима

### Fixed
- Исправлен баг с потерей типа объекта при чтении из кэша

### Known Issues
- **Не используйте `decode_responses=True`** в Redis-клиенте при включённом `use_pickle=True`
